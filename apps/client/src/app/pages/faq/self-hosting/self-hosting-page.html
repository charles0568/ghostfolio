Frequently Asked Questions (FAQ)

在「常見問題（FAQ）」中快速找到自架 Ghostfolio 常見問題的解答。

如何開始？ 若你想在自己的基礎設施上執行 Ghostfolio，請參考 GitHub 上的原始碼與相關說明。 Ghostfolio 支援哪些家用伺服器系統？ 社群已將 Ghostfolio 移植到多種家用伺服器系統，包括 CasaOS、 Home Assistant、 Runtipi、 TrueCharts、 Umbrel 與 Unraid。 如何新增一種貨幣？

Ghostfolio 會根據所有交易紀錄自動管理貨幣。若需要額外的貨幣，也可以手動新增。

  1. 開啟「管理」控制台
  2. 切換到「市場資料」分頁
  3. 點選右下方的「+」按鈕
  4. 切換到「新增貨幣」
  5. 輸入貨幣代碼，例如歐元的 EUR
  6. 使用「依貨幣篩選」
  7. 找到對應項目，例如 USDEUR
  8. 在對話框中點選「蒐集歷史市場資料」
 如何解決 找不到匯率 的錯誤？

在 Ghostfolio 中，相關的歷史匯率資料需要由你自行提供，可以一次性匯入。當你看到類似 「2024-01-01 找不到 EUR 到 USD 的歷史匯率」 的錯誤時，請依下列步驟處理：

  1. 開啟「管理」控制台
  2. 切換到「市場資料」分頁
  3. 使用「依貨幣篩選」
  4. 找到項目 USDEUR
  5. 在對話框中點選「蒐集歷史市場資料」

對於衍生貨幣（如 GBp），請確保已蒐集其母貨幣（如 GBP）的資料。

「平台」這個概念是什麼？ 「平台」用來將多個帳戶分組，例如同一家銀行的儲蓄帳戶與交易帳戶。把帳戶歸到同一個平台，介面上會顯示統一的圖示，也能讓你掌握各平台的風險集中度。 如何新增一個平台？
  1. 開啟「管理」控制台
  2. 切換到「設定」分頁
  3. 點選「新增平台」按鈕
 如何新增一個標籤？
  1. 開啟「管理」控制台
  2. 切換到「設定」分頁
  3. 點選「新增標籤」按鈕
 支援哪些資料供應商？ COINGECKO、GHOSTFOLIO（需訂閱 Ghostfolio Premium）、MANUAL 與 YAHOO 是官方支援的資料供應商， 其餘資料供應商皆視為實驗性質。 我可以使用專業資料供應商嗎？ 可以。訂閱 Ghostfolio Premium 後，即可透過 API 金鑰使用專業資料供應商（GHOSTFOLIO）。 會新增資料供應商 X 嗎？ 目前沒有擴充核心資料供應商的計畫。不過你通常可以透過 MANUAL 資料來源搭配 scraper 設定，把想要的網站資料整合進來。 如何設定比較基準（Benchmark）？

若要將你的績效與《Bitcoin》、《Gold》或《S&P 500》等比較基準對照（即「比較對象…」功能），請依下列步驟設定：

  1. 開啟「管理」控制台
  2. 切換到「市場資料」分頁
  3. 選擇一檔資產設定
  4. 在對話框中勾選「納入比較基準 / 市場」
如何新增自訂資產？

若想追蹤資料供應商沒有提供的資產，可以依下列方式建立自訂資產：

  1. 開啟「管理」控制台
  2. 切換到「市場資料」分頁
  3. 建立一檔資產設定
  4. 選擇「手動新增」並輸入一個唯一的代碼
  5. 編輯該檔資產設定
  6. 透過搜尋該代碼新增一筆交易紀錄
 如何設定市場頁面？
  1. 開啟「管理」控制台
  2. 切換到「市場資料」分頁
  3. 選擇一檔資產設定
  4. 在對話框中勾選「納入比較基準 / 市場」

請注意：資料會被快取，設定後可能需要幾分鐘才會反映在介面上。

支援哪些裝置？ Ghostfolio 在所有現代瀏覽器中都能執行，無論是智慧型手機、平板電腦或桌上型電腦。 自架版本的 Ghostfolio 在 App 商店有對應的行動 App 嗎？ 沒有。自架版本的 Ghostfolio 在 App 商店沒有對應的行動 App。 不過你可以把網頁應用程式加到主畫面（例如在 Google Chrome 中選「加到主畫面」），體驗與 App 幾乎相同。 備份的最佳做法是什麼？ 建議定期透過完整的資料庫匯出（database dump）備份你的資料。 還有其他問題嗎？ 歡迎加入 Ghostfolio Slack 社群、在 X 上發文給 @ghostfolio_ ，或到 GitHub 發起討論。
